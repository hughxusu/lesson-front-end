# 搭建开发环境

mac电脑下安装flutter需要首先安装Xcode命令行工具

```shell
xcode-select --install
```

查看Xcode命令行工具的版本与升级

```shell
xcode-select --version
softwareupdate --all --install --force
```

[下载安装包](https://docs.flutter.cn/install/manual)，下载后将安装包解压的到指定的文件夹下，如：`~/opt`。在`~/.zshenv`文件中设置flutter环境变量和[中国大陆代理](https://docs.flutter.cn/community/china/)

```shell
# flutter环境变量
export PATH="/Users/xusu/opt/flutter/bin:$PATH"

# flutter中国代理
export PUB_HOSTED_URL="https://pub.flutter-io.cn"
export FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"
```

安装完成后测试flutter是否安装成功

```shell
flutter --version
dart --version

# 检查桌面开发还要哪些环境
flutter doctor
```

## Trae的Dart开发环境

安装dart插件和Code Runner插件

> [!warning]
>
> 运行Run Code是出现错误：/bin/sh: dart: command not found
>
> 在首选项>设置>Editor设置>去设置>Run Code Configuration设置
>
> ```json
> "code-runner.executorMap": {
>     "dart": "~/opt/flutter/bin/dart"
> }
> ```

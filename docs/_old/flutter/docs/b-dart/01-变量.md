# 从变量开始

创建`hello.dart`在文件，在文件中输入如下文本，并执行程序。

```dart
void main() {
  print('hello world');
}
```

* 在Dart语言中，所有要被执行的程序，都需要放到`main`方法中。
* 一段程序`main`方法只能有一个。
* `void`表示方法没有返回值，如果省略表示方法有返回值。
* Dart语言每行介绍需要加`;`

程序的本质

1. Dart程序就是一个拓展名为`.dart`的文本文件，可以使用任意文本编辑器编写。
2. Dart程序可以由编译器编译，这需要程序符合Dart的语法规则。

## 定义变量

Dart是一门强类型的语言可以指定变量的类型，同时也可以实现变量的类型推到。

```dart
void main() {
  String message = 'hello world';
  print(message);

  var name = 'Harry Potter';
  print(name);

  message = 'hello dart';
  print(message);
}
```

上面的代码分别定义了`message`和`name`变量

* `String`指明了数据类型为字符串。
* 通过`var`关键字来指定变量，会自动推导变量类型。
* 使用`=`用来给变量赋值`变量名 = 值（字面量）`。
* Dart中没有`let`关键字。
* `print`函数可以打印变量里的信息。
* 变量定义后，后续代码中可以直接使用。

变量一旦定义，程序执行过程中，不能改变变量类型

```dart
void main() {
  var message = 'hello world';
  print(message);

  message = 100;
  print(message);
}
```

> [!attention]
>
> Dart是强类型语言。上面代码报错，变量类型不能随意变更。

变量可以理解为一种标签，指向特定的值。


### 变量的命名规则

**标识符**：是程序员定义的变量名、函数名等。标识符定义时应做到见名知义。

Dart中标识符定义的规则：

1. 必须由数字、字母、下划线和美元符($)组成。
2. 开头不能是数字。
3. 区分大小写。
4. 不能与保留字和关键字重名。

```
stuedent1
stuedent#12
one_boolean
one-Boolean
Object2
2Object
$Object
oneInt
_test
test!1
unit(L)Value
tom_jerry
tom&jerry
CPU
C.P.U
```

如果定义的变量名与关键字冲突，可以在其末尾追加下划线`_`

```dart
void main() {
  var class_ = '信息与计算科学2班';
  print(class_);
}
```

### 常量

Dart中使用`final`和`const`修饰符定义常量

1.  `const`定义值不变，一开始必须赋值。

```dart
void main() {
  const PI = 3.14159;
  print(PI);
}
```

* `final`可以开始不赋值，但只能赋一次。`final`是惰性初始化，即在运行时第一次使用前才初始化。

```dart
void main() {
  final PI = 3.14159;
  print(PI);

  final E;
  E = 2.71828;
  print(E);

  final now = new DateTime.now();
  print(now);

  // const currnt = DateTime.now();
  // print(currnt);
}
```

* 使用`const`定义时间类会报错。

## 认识 Bug

修改代码如下，并执行程序。

```dart
void main() {
  var message = 'Hello, Dart!';
  print(mesage);
}
```

执行结果如下

```shell
Error: Undefined name 'mesage'.
  print(mesage);
```

* 上面的提示说明程序在执行过程中出现了错误。

程序不能正常执行，或执行结果不符合预期，俗称Bug。产生的原因：

1. 语法和拼写错误。
2. 计算异常，如：`num = 3 / 0`
3. 业务逻辑错误，**无法通过集成开发环境和程序执行发现**，只能通过测试和用户使用发现。

> [!warning]
>
> 程序员要学会发现和解决程序编写中产生的Bug。一般工作中写程序的时间占工作时间的三分之一，剩下的三分之二的都用来调试和修改Bug。

## 代码规范

任何语言的程序员，编写出符合规范的代码，是开始职业生涯的第一步。变量的命名习惯

<img src="https://raw.githubusercontent.com/hughxusu/lesson-py/develop/images/base/p9zxnxg.jpg" style="zoom:67%;" />

Dart中统一使用驼峰命名法

```dart
void main() {
  var greetingMessage = 'Hello, Dart!';  // 小驼峰式命名法
  print(greetingMessage);
  var GreetingMessage = 'Hello, World!'; // 大驼峰式命名法
  print(GreetingMessage);
}
```

* 普通变量和函数使用小驼峰式命名法。
* 类通常使用大驼峰式命名法。如：`DateTime`。
* 与关键字冲突，可以在变量末尾追加下划线，如：`class_`。
* 保证变量名描述性强的同时，尽可能使其简短。（用变量名来说明变量的含义）
* 使用`is`或`has`前缀来修饰布尔值。如：`isMale = True`

## 代码注释

在程序中给某些代码添加说明称为注释，注释的内容会被编译器忽略。注释能够增强程序的可读性：

1. 方便自己回忆代码细节。
2. 帮助其他程序员理解代码流程或原理。

```dart
/*
 * 多行注释
 * 可以跨越多行
 */
void main() {
  print('hello dart');  // 单行注释
}
```

良好注释的指导原则：

1. 注释不应该复述代码（对于一目了然的操作，不需要用注释描述）。
2. 注释应该提供读者无法从代码中读出的信息，解释代码为啥这么做。
3. 指引性注释：简要概况代码的流程或功能。
4. 实际工程中不要用注释来屏蔽以前淘汰的代码。
